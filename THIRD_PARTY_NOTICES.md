# ForgeKi third-party notices

ForgeKi incorporates open-source JavaScript and Rust dependencies. The Phase 7 production inventory
reported MIT, Apache-2.0, ISC, BSD, 0BSD, BSL-1.0, CC0-1.0, Unicode-3.0, Zlib, MPL-2.0, and compatible
dual-license expressions. MPL-2.0 components retain their file-level license obligations; dependency
license expressions that offer MIT or Apache-2.0 alternatives are consumed under a compatible option.

The release CycloneDX SBOM records exact package names and versions. The authoritative license texts
remain in each dependency package and upstream repository. This notice is an engineering inventory,
not legal advice or a legal guarantee. Maintainers must review the generated license report and SBOM
for every release candidate.
