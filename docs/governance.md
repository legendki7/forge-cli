# Governance

ForgeKi is currently maintained by the repository owner and any maintainers they appoint. Project
direction is maintainer-led, while community contributions are reviewed through GitHub pull requests.

Maintainers decide scope, compatibility, release timing, and whether a contribution meets the
project's deterministic, local-first, and security requirements. Security-sensitive changes require
explicit maintainer approval and may need additional review before merge.

This lightweight model does not create or imply a company, foundation, formal membership program,
or guaranteed release schedule. It can evolve transparently if the contributor community grows.
